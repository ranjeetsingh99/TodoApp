# Todo App

A simple **Todo List web application built with ASP.NET Core MVC**.

This project is created **for learning and practice purposes**. The main goal is to understand the basic concepts of building a web application with .NET, MVC, Entity Framework Core, and SQL Server.

## Features

* Add new tasks
* View all tasks
* Mark tasks as completed
* Edit tasks
* Delete tasks
* Store tasks in a database

## Technologies Used

* C#
* ASP.NET Core MVC
* .NET 8
* Entity Framework Core
* SQL Server
* Razor Views
* HTML & CSS
* Git & GitHub

## Project Purpose

This is not a production application. It is a beginner-level project created to practice:

* MVC architecture
* Models, Views, and Controllers
* CRUD operations
* Entity Framework Core
* Database migrations
* Dependency Injection
* Razor syntax
* Basic application structure in ASP.NET Core

## Getting Started

### 1. Clone the repository

```bash
git clone <repository-url>
```

### 2. Open the project

Open the project in **Visual Studio** or **Visual Studio Code**.

### 3. Configure the database

Update the connection string in `appsettings.json` according to your SQL Server setup.

### 4. Create the database

Run the Entity Framework Core migrations:

```bash
dotnet ef database update
```

### 5. Run the application

```bash
dotnet run
```

Then open the URL shown in the terminal.
